# DCCNN ARPES

Reproducible tooling for ARPES 2D-cut denoising with DCCNN.

## Development setup

Install the locked development environment with:

```powershell
uv sync --extra dev
```

The package provides four initial command-line entry points:

```powershell
dccnn-data --help
dccnn-train --help
dccnn-eval --help
dccnn-denoise --help
```
